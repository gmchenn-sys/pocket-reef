# Visual direction

Windows98-inspired gray chrome (#c0c0c0), navy title bar (#000080), white highlight / gray shadow bevels, inset aquarium and status areas, and raised controls. System fonts require no external network. The layout and wording are original to Pocket Reef; no reference creator's UI assets or screenshots are bundled.

The240×240 aquarium keeps pixel glyphs crisp, matches native RGB565 colors, and uses independent wandering rather than fixed lanes. Feeding, ownership and cross-screen protocols are independent of the window styling.
